# 팝 셰퍼드 (Pop Shepherd)

적을 직접 죽이지 않고, 날려서 같은 색끼리 부딪쳐 터뜨리는 서바이벌 게임. 이 폴더는 그 **코어 시뮬레이션**이다. 화면 없이 돌고, 규칙은 전부 자동 테스트로 묶여 있다.

설계 문서: "팝 셰퍼드 구조 트리와 로드맵" (코어 규칙 명세 탭), "팝 셰퍼드 무기 밸런스" 시트.

## 실행

Node 22.18 이상이 필요하다 (TypeScript 파일을 Node가 직접 실행한다).

```bash
npm install
npm run check      # 타입 검사 + 전체 테스트
npm test           # 테스트만
npm run sim        # 봇이 M1 검증장을 5판 플레이하고 M1 기준 판정을 출력
npm run sim -- --seeds 10 --stage stage01 --character cue --weapons kick:2,shockwave:1
```

`npm run sim`의 출력은 시드별 결과, 무기별 **실측 타격 수**(밸런스 시트의 가정값과 비교), M1 통과 기준 판정이다.

## 원칙

- **시뮬레이션은 결정적이다.** 60Hz 고정 틱, 모든 무작위는 시드 난수 하나. 같은 시드면 상태 해시까지 같다 (`tests/sim.test.ts`).
- **무기·캐릭터·스테이지는 데이터다.** 코드에는 동작 모듈만 있다. 무기 JSON의 LP가 목표 ±15%를 벗어나면 테스트가 실패한다 (`tests/data.test.ts`).
- **규칙 수치를 바꾸면 설계 문서도 고친다.** `src/core/rules.ts`의 주석이 명세 항목 번호를 가리킨다.

## 아직 없는 것

- 화면(렌더링)과 입력 장치. 지금은 봇 입력과 테스트 입력만 있다.
- 무기 Lv4 이후 분기·진화 효과, 올가미·페인트·회오리·반사벽 동작 (데이터는 있음, `implemented: false`).
- 경험치 곡선과 레벨업 카드, 정비 상점, 영구 강화.
