## 2. 버그 점검
훑은 곳: `levelup.ts`, `chest.ts`, `shop.ts`, `save.ts`, `core/game.ts`(클리어·픽업), `combat/impacts.ts`, `weapons.ts`(회오리·쿨다운), `web/main.ts`(카드·상점·카운트다운).
- 무한 루프: `for(;;)` 4곳 (`levelup.validateFrontChoice`, `shop.botShop`, `meta`, `save.botSpend`) 모두 매 회 선택지·골드·코인이 줄어 끝난다.
- 쿨다운 0 나누기: `cooldownOf`의 `1 − stats.cooldown`은 `COOLDOWN_CAP`으로 막혀 있다 (`passives.ts`).
- 결정론: 위 표와 같다.
- 세이브 호환: `parseSave`가 버전 1·2를 읽고 없는 노드·넘친 레벨·선행 위반을 고친다. 테스트 설정 화면도 같은 경로를 거친다.
- 두 모드 분기: `ballMode` 분기는 `docs/2026-11-26-두모드-점검.md`에 정리. 회오리만 어긋나 있어 이미 고쳤다.

### 이번 점검에서 고친 것
- 주석 2곳이 실제 동작과 달랐다 (`levelup.ts`는 "정비 상점의 진화 상자", `shop.ts openShop`은 "진화 상자를 먼저 열고"). 진화는 엘리트·보스 상자에서 받으므로 주석을 맞췄다. 동작은 안 바뀐다.

(같은 날 앞선 작업에서 고친 버그: 상자·상점 갈래 자동 선택, 낡은 공 원인으로 무기가 날린 적이 터지던 것, Lv4+ 카드가 "갈래를 고른다"로 표시되던 것, 색 공 끔에서 회오리가 튕기던 것.)

### 남은 의심 (확신 없음, 고치지 않음)
1. 정비 상점의 `ShopState.evolved`는 항상 빈 목록인 죽은 필드다. 진화 시점을 기획서대로 되돌릴지 정해지면 같이 정리.
2. (해결) 보스 상자는 클리어 수거 범위 예외로 늘 챙긴다.
3. 1.6 막힘 "분당 1회 미만" 목표는 이번 점검에서 재지 않았다.
4. 해금 "무기·하드 모드"는 미구현 (트리 요약에는 언급만).
