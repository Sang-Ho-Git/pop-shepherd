# 구조 트리 요약 (기획 문서 "팝 셰퍼드 구조 트리와 로드맵"에서 옮김, 11/26)

점검용 요약이다. 원문은 claude.ai 문서(11/19 작성, 11/21 현황 갱신). 이후 사용자 결정으로 바뀐 것은 아래 "이후 결정"에 적었다.

## 1. 코어 규칙 (●=확정값)
- 1.1 조작: 8방향 이동 + 휘슬(스페이스) 1버튼. (이후 색 공 던지기 추가)
- 1.2 물리: 감속 2.5/s, 발사 종료 120px/s, 울타리 쿠션, 당구 충돌
- 1.3 적 상태: 평소 · 발사 · 기절 → 팝/처치, 같은 색 응집
- 1.4 충돌 매치: 접근 속도 60px/s 이상이 부딪침, 접촉 +4px, 무지개·회색 규칙
- 1.5 매치 보상·연쇄: 3마리부터 팝 충격파, 5마리 폭탄, 단계당 ×1.5, 연쇄 인정 1.0초
- 1.6 막힘 방지: 직접 처치 경험치 20%, 막힘 = 화면에 적이 있는데 10초 동안 팝 없음 (목표 분당 1회 미만)
- 1.7 출현 보정: 짝(같은 색 2마리) 2~3개씩 소환, 남은 색 가중치 3, 구간별 색 제한

## 2. 런 안 성장
- 레벨업 카드 3장 중 1장. 무기 슬롯 6, 패시브 슬롯 6.
- 무기 Lv1→2→3→Lv4 분기(A/B)→5→6→Lv7 완성. **Lv4 카드는 고르는 순간 A/B 선택 창** (상자·상점 경로도 동일해야 함).
- 진화: Lv7 + 짝 패시브 → 다음 정비 화면에서 진화 상자. **진화해도 고른 분기의 Lv7 효과 유지**.
- 채움 카드(전부 찼을 때): 골드 50 또는 체력 회복 (11/26 회복 30% → 10%로 사용자 피드백 반영).
- 카드 가중치: 보유 무기 레벨업 35, 보유 패시브 25, 새 무기 20, 새 패시브 20. Lv5 이상 무기의 짝 패시브 미보유면 그 패시브 ×2.
- 경험치 곡선 목표: 런 전체 레벨업 약 45번(스테이지당 4~5번).
- 정비 상점: 스테이지 사이.

## 3. 영구 강화·해금
- 가지 끝은 플레이 방식을 바꾸는 효과, 중간 노드는 숫자만.
- 해금은 코인이 아니라 업적(캐릭터, 무기, 하드 모드).

## 4. 코드 구조·원칙
- 데이터 주도: 무기·캐릭터·적·스테이지는 data/ JSON, 코드는 동작 모듈(pulse, directional, pull, zone, projectile, orbit, wall) + 태그 보정.
- 고정 틱 60Hz + 시드 난수(sfc32): 같은 시드면 같은 판 (시뮬 결정론).
- 시트와 게임 순환: 밸런스 시트 ↔ data, LP ±15% 검사 테스트.

## 이후 사용자 결정 (트리와 달라도 의도된 것)
- 색 공 던지기 규칙이 기본(당구·쿠션), 예전 규칙은 끄기 옵션. 스테이지 15개.
- 영구 강화: 캐릭터별 트리(공통 19 + 전용 3), 코인 = 스테이지 i 클리어 0.1×i², 완주 +60, 남은 골드 몫. 남은 골드 → 코인.
- 강화 0 봇 완주 약 10% (사람 약 20% 가정), 보스는 패턴·약점·그로기·근처 팝 피해.
- 연쇄 규칙 그대로(충격파로 날아간 적이 1초 안에 같은 색과 3마리 이상), 휘슬은 밀기 전용, 연출로 보이게.
- 같은 색 응집 유지(가다듬은 버전), 회오리는 둔화·삭제(두 모드 공통).
