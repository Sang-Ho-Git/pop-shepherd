# 상자를 정비 상점 앞에서 열기 (11/26, 사용자 결정)

"다음 정비 상점에서 진화하는 거로 하고 화면에 먹은 상자를 표시해 주는 방식으로 가자."

## 규칙
- 엘리트·보스 상자는 주워도 바로 열지 않고 `g.held`에 모은다. HUD 위쪽(골드 옆)에 `🎁×n ★보스×n`, 보스 상자가 있으면 금색, 주울 때 개수가 튕긴다.
- 스테이지 클리어 뒤 정비 상점 앞(`renderChestScreen`)에서 하나씩 연다. 상자 하나의 효과는 전과 같다 (엘리트: 진화 1개 또는 강화 1, 보스: 진화 전부 + 강화 3). 갈래가 필요한 Lv4는 열 때 갈래 창이 뜨고 끝나면 상자 화면으로 돌아온다.
- 다 열면 정비 상점의 진화 상자가 한 개 더 (`grantEvolutionChest`): 진화 조건(Lv7 + 짝 패시브)을 채운 무기가 남아 있으면 하나를 진화시킨다. 트리 원문의 "다음 정비 화면에서 진화 상자".
- 마지막 스테이지(15)는 상점이 없어 상자만 열고 결과로 간다 (진화 상자 없음).
- 죽거나 시간 초과로 끝나면 열지 않은 상자는 사라진다 (세이브·이월 없음).
- 클리어 때 보스 상자는 거리와 상관없이 모아진다 (엘리트 상자는 줍는 거리 ×1.1 안만).
- 시뮬: 클리어 직후 `settleChests` (모은 상자 전부 + 진화 상자), 상점 구매 전에 한다.

## 난이도 측정 (색 공 규칙, 영구 강화 0, 36시드×4, 보정 없음)
| 캐릭터 | 완주 | 이전(72시드, 비교용) |
|---|---|---|
| 양치기 | 1/36 | 9/72 |
| 큐 | 2/36 | 10/72 |
| 올리 | 5/36 | 5/72 |
| 팔레 | 4/36 | 6/72 |
| 합계 | 12/144 (8.3%) | 30/288 (10.4%) |

합계는 −2.1%p로 ±4%p 안이다. 캐릭터별로는 양치기·큐가 낮아지고 올리·팔레가 오른 쪽으로 갈렸다 (표본이 작아 오차가 크다). 진화는 판당 약 3~3.7개로 늘었다 (정비 상점 진화 상자 덕분).
