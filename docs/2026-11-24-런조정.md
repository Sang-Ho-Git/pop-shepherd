## 1. 회오리 (피드백: "공을 흩트려놓아서 공을 쏠 때 오히려 방해")

색 공 규칙(기본)에서만 동작을 바꿨다. 기존 규칙은 예전처럼 접선 방향으로 튕긴다 (무기 LP 보정·테스트 그대로).
비교 실험용으로 `RULES.ball.orbit.legacy = true`면 색 공 규칙에서도 예전 동작 (`legacyOrbit` 조건).

| 항목 | 값 | 이유 |
|---|---|---|
| 튕김 | 없음 (7B 강풍만 바깥으로 16~20px 살짝 밀기) | 무리 모양이 그대로 남아 공을 쏠 자리를 망치지 않는다 |
| 둔화 | 칼날에 닿으면 `slowSec`초 동안 `slow`만큼 (Lv1 −35%/1.5초, Lv2~ −40%, 갈래 B −50~60%/2~2.5초) | 도움이 되는 스킬로 남긴다. 같은 색 응집 속도도 같이 준다 |
| 누적 삭제 | 같은 적이 `strikes`번 맞으면 회색 연기로 사라짐 (Lv1~6 4번, 7A 3번) | 경험치·골드·팝·점수 없음 (`stats.bladeVanished`로 따로 셈) |
| 한 바퀴 상한 `cap` | Lv1~2 3마리, Lv3 4, 4A·5A 5, 6A·7A 6, 4B~7B 4~5, 사이클론 8 | 다 쓰면 칼날이 흐려지고 다음 바퀴까지 쉰다 → 무적 오라 방지 |
| 회전 주기 하한 | 0.6초 (`RULES.ball.orbit.minPeriod`), 같은 적 재타격 0.8초 | 7A의 0.4초 회전이 촘촘한 벽이 되지 않게 |
| 엘리트·보스 | 둔화 절반만, 지우지 않음 | 보스전은 공으로 |
| 7B 완성 | 마지막 일격 바로 앞의 일격은 1초 멈춤 | 갈래 B의 "제어" 성격 |
| 사이클론 (진화) | 반경 190, cap 8. 색 공 규칙에서는 빨아들이기 끔 | 끌어오면 적이 플레이어 쪽으로 몰린다 |

웹: 칼날 꼬리 호, 무뎌지면 흐리게, 둔화된 적은 하늘색 점선 테, 맞은 횟수는 머리 위 점, 삭제는 회색 연기 (팝 연출과 구별).
스크린샷: `docs/shots/whirl-lv3.png`, `whirl-6A.png`, `whirl-7B.png`, `whirl-evo.png` (`node tools/shot-whirl.mjs`, 점검용 `window.__pop.give(무기, 레벨, 갈래)`).

## 2. 마무리 시간 없앰 (피드백: "15초 추가 시간이 의미가 없는 거 같음")

- `RULES.stage.wrapUpSeconds` 10 → **0**: 생존형은 시간이 끝나면, 처치형은 보스·엘리트를 쓰러뜨리면 바로 클리어. 남은 적은 사라지고 골드·상자는 자동으로 줍는다.
  0보다 크게 하면 예전 마무리 시간이 돌아온다 (`wrap10` 조건). 마무리 배너 문구도 "15초"(틀림) 대신 규칙 값에서 만든다.
- 보정: 마무리 시간 팝이 스테이지 경험치의 약 8.3%였다 (31bc547, 올리·양치기 12판 118스테이지 측정, 마무리 시작 때 남은 적 평균 66마리).
  대신 클리어 때 **남은 일반 적 경험치 × `clearXpRatio` 1**을 준다 (약 60% 보전). 상점 화면에 "남은 적 N마리가 흩어지며 경험치 +X".
- 런 길이: 완주 약 32분 → **29.8분**.
- 테스트: stage.test(바로 클리어, 클리어 경험치), bosses.test(처치하면 바로 클리어).

## 3. 이동 속도 패시브 "가벼운 발굽" (피드백: "캐릭터가 느리고 몹이 빠른 것도 사용자의 선택")

- `data/passives.json` `swift_hooves`: 이동 속도 +8%/레벨, 최대 5 (+40%). 레벨업 카드·정비 상점에 나온다. 진화 짝은 없다 (털옷처럼 생존 패시브).
- 봇 점수: 스테이지 8부터(`RULES.cards.botSpeedFrom`) 진화 짝만큼(88), 앞에서는 낮게(45). 확정 데이터에서 288판 중 41판이 골랐고 평균 4.7레벨.
  패시브 칸이 6개라 늦게 고르는 경우가 많다 → 사람에게는 "후반 빠른 양을 피할지, 화력을 더할지"의 선택지.

## 4. 반사벽 변경(31bc547) 영향

| 커밋 | 11~46 | 47~82 |
|---|---|---|
| 96e79e1 (반사벽 변경 전) | 25/144 (양치기 6, 큐 5, 올리 7, 팔레 7) | (문서 값 29) |
| 31bc547 (반사벽 변경) | **10/144** (2, 2, 1, 5) | **8/144** (4, 0, 2, 2) |

반사벽 변경만으로 완주가 25 → 10으로 줄었다. 예전 벽은 플레이어 앞에 서서 걸어오는 적을 막는 방어 구실도 했는데, 무리 뒤에 서면서 그 몫이 없어졌다.
진화 만화경은 ㄷ자 주머니가 몇 벌씩 겹쳐 화면을 가로지른다 (`docs/shots/whirl-evo.png`).
같은 조건(이 브랜치 1차)에서 반사벽을 빼면 17 → 22, 동시 벽 상한 3장(`wallCap3`)은 11 (잡음 범위, 효과 없음).
반사벽 자체는 고치지 않고(설계 결정이라 메인 세션 몫) 아래 난이도 보정으로 메웠다. 확정 데이터에서 반사벽을 가진 런의 후반 완주율은 28%로 평균 수준.
남는 문제: 만화경이 겹쳐 그려지는 화면 혼잡, 벽의 방어 몫이 사라진 것 — 사람 손으로 확인이 필요하다.
