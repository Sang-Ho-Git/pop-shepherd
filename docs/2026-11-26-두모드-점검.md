# 색 공 규칙 켬/끔 두 모드 일관성 점검 (11/26)

피드백: "색공던지기를 off하고 킥으로만 테스트하니 … 회오리가 둔화시키지 않고 몸을 떨어뜨린다".
`g.ballMode`로 갈라 둔 코드는 아래가 전부다 (`grep ballMode src web`). 최근 변경 중 모드로 갈린 것은 회오리뿐이었다.

| 변경/규칙 | 켬 | 끔 | 판정 |
|---|---|---|---|
| 회오리 둔화·삭제 (11/24) | 둔화, 4번 맞으면 연기 | **예전 튕기기** | 어긋남 → 두 모드 공통으로 고침 (`tickOrbit`, `RULES.ball.orbit.legacy`로만 예전 동작). 회오리 칼날 그리기의 "무뎌짐" 표시도 공통 |
| 반사벽 1세트·길이 상한 (areaCap) | 적용 | 적용 | 일관 (모드 분기 없음) |
| 자석 토템 반경 상한 | 적용 | 적용 | 일관 |
| 그로기·보스 팝 피해 | 팝에서 적용 | 팝에서 적용 | 일관 (`popCluster` 공통). 약점 공 직격은 공이 있어야 해서 켬 전용(당연) |
| 회복 감소(채움·상자·우유병 하향) | 적용 | 적용 | 일관 |
| 클리어 수거 범위 ×1.1 | 적용 | 적용 | 일관 (`advancePhase`) |
| 무기가 날린 적이 낡은 원인(ball)으로 터지던 버그 | 영향 | 영향 없음 (끔은 늘 터짐 허용) | 일관 (끔은 원래 무기·충돌 모두 팝 가능) |
| 킥 방향 보정(같은 색 쪽)·쿨다운 배율 | 있음 | 없음(이동 방향) | 의도된 차이 |
| 갈래 즉시 팝·압축 팝 (`popNow`) | 쓰지 않음 | 씀 | 의도된 차이 (켬은 터뜨리는 것이 공) |
| 공 던지기·쿠션 보너스·약점 공·공 전용 패시브(`ballOnly`) | 있음 | 없음 | 의도된 차이 |
