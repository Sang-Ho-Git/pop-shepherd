### 손맛 (트리 4.2) — 넣음
- WebAudio 합성 효과음: 팝, 공 던지기, 공 붙음, 피격, 휘슬, 레벨업, 보스 등장, 상자, 클리어.

- 소리 켜기/끄기: 타이틀 버튼, 또는 M 키.

### 페인트 총: 무엇이 센가
- 먼저 완주율로 비교했다 (같은 시드, 양치기·큐·올리 6판씩). 차이가 거의 없었다.
  - 기존 규칙: 보통 14/18, 페인트 총 금지 13/18
  - 색 공 규칙: 보통 16/18, 페인트 총 금지 14/18
- 그래서 지표를 바꿨다: 팝마다 누가 일으켰는지 센다 (무기·공·휘슬·폭탄, 연쇄 팝은 처음 일으킨 쪽 몫). `stats.popsBy`, 도구 `tools/share.ts`.
- 검증장, 무기 하나만 바꿔 끼우고 나머지는 충격파·토템 Lv3 (4판씩):

| 무기 | 기존: 그 무기 몫 | 색 공: 무기 몫 / 공 몫 |
|---|---|---|
| 킥 Lv3 | 23% | 17% / 28% |
| 올가미 Lv3 | 31% | 24% / 23% |
| 회오리 Lv3 | 29% | 15% / 28% |
| 페인트 총 Lv3 | 56% | 36% / 31% |
| 페인트 총 7A / 진화 | 62% / 62% | 44% / 48% |

- 결론: 페인트 총은 "칠하고 → 옆 무리로 밀어 넣으면 → 알아서 터지는" 구조라, 플레이어가 할 일을 대신한다. 완주율보다 이게 "사기"의 정체다. 색 공 규칙에서는 공보다 더 많이 터뜨린다.

### 기믹 적·바위 (트리 3.2, 3.3) — 시험 중
- 가시 젤리: 플레이어 무기로 밀리지 않는다 (팝 충격파·휘슬은 밀린다). 매치로는 터진다. 스테이지 4부터 짝의 12~18%.
- 겁쟁이 양: 220px 안으로 다가가면 도망간다. 빠르다(95). 스테이지 6부터 12~18%.
- 바위: 스테이지 7 "돌무지 고개"에 6개. 길을 막고, 날아간 적은 울타리처럼 튕긴다 (쿠션).
- 화면에도 그렸다: 가시, 귀, 회색 돌.

### 처음 하는 사람 안내 (트리 4.3·4.4) — 넣음
- 스테이지 1에서 시간에 맞춰 짧은 안내가 하나씩 뜬다 (처음 세 판만). 규칙(색 공 / 기존)에 맞는 문장.
- 색 공: 조준·던지기 → 3마리 채우면 팝, 빛나는 무리 → 하나뿐이면 붙음 → 연쇄와 휘슬.
- 기존: 자동 무기 → 세게 부딪혀야 팝 → 천천히 붙은 무리는 짝 → 휘슬. (아침에 말씀하신 "붙어 있는데 안 터진다"를 화면에서 설명)

### 페인트 총 해결안 비교 → "밀지 않기 + 공 색으로 칠하기" 채택
검증장, 페인트 총 Lv3 / 7A / 진화 (4판씩). 목표는 다른 무기 수준(25~30%).

| 해결안 | 기존: 페인트 몫 | 색 공: 페인트 몫 / 공 몫 |
|---|---|---|
| 지금 | 56~62% | 36~48% / 29~31% |
| 쿨다운 1.6배 | 38~53% | 32~39% / 30~31% |
| 밀지 않기 | 3~6% | 3~4% / 36~43% |
| 1초 마름 (칠한 적은 1초 동안 매치 안 됨) | 4~10% | (재지 않음) |
| 밀지 않기 + 마름 | 2~10% | 2~4% / 36~38% |
| 공 색으로 칠하기 (밀지 않음) | (기존 규칙에는 해당 없음) | 3~5% / 32~39% |

- 쿨다운만 늘리면 여전히 가장 많이 터뜨린다.
- 밀지 않으면 페인트가 혼자 터뜨리지 않는다. 대신 칠해 둔 적을 다른 무기·공이 터뜨린다. 분당 팝(약 150)과 사망은 그대로.
- 런 (4캐릭터 × 4판, 시드가 적어 흔들림이 크다):

| 규칙 | 예전 페인트 | 바꾼 페인트 |
|---|---|---|
| 기존 | 6/16 | 5/16 (밀지 않기) |
| 색 공 | 11/16 | 8/16 (공 색으로 칠하기) |

- 채택: 페인트 총은 칠하기만 한다. 색 공 규칙에서는 지금 든 공 색으로 칠해, 내 다음 공이 터뜨릴 판을 깐다. (`RULES.paint`, 예전 동작은 `tools/variants.ts`의 oldPaint)
- 함께 볼 것: 이 방향이 손맛에 맞는지. 아니면 "1초 마름"(칠한 뒤 잠깐 기다렸다 터짐)도 후보.
- 참고: 이 런에서 기존 규칙 완주가 어제(72%)보다 낮다 (6/16). 오늘 넣은 기믹 적·바위 때문인지 따로 재는 중.

### 기믹 적·바위 — 남김 (색 공 규칙의 난이도 장치)

### 휴대폰 — 고침
- 휴대폰용 "바꾸기" 버튼.
- 세로 화면에서 게임이 아주 작게 보이던 것: 짧은 변에 월드 620px이 들어오게 확대.

### 맵 기믹 5개 채움 (트리 3.3 목표 5개 이상)
| 스테이지 | 기믹 | 내용 |
|---|---|---|
| 2 갈대 개울 | 개울 | 가로 띠 안에서 플레이어·적 60% 속도 |
| 4 안개 골짜기 | 안개 | 플레이어 둘레 380px만 보인다 (화면 전용) |
| 6 꽃가루 들판 | 꽃 범퍼 | 걸어서 닿은 적을 튕겨 내고, 날아온 적은 1.3배로 튕긴다 |
| 7 돌무지 고개 | 바위 | 길을 막고, 날아간 적은 쿠션으로 튕긴다 |
| 8 폭풍 초원 | 돌풍 | 12초마다 4초. 걷는 것은 조금, 날아가는 적·색 공은 크게 휜다 |

- 색 공은 바위·범퍼에서도 튕긴다 (쿠션 횟수를 쓴다).
- 돌풍은 봇 기준 난이도에 영향이 거의 없다 (있음 15/24, 없음 14/24). 봇은 바람을 읽지 않는다. 사람에게는 조준 거리를 주는 장치라 남겼다.
- 꽃 범퍼는 난이도를 조금 낮춘다 (있음 15/24, 없음 11/24): 범퍼가 일으키는 뜻밖의 충돌·연쇄가 돕는다. 지금 전체 62.5%로 목표 언저리라 남겼다.

### 휴대폰 세로 화면 출현 위치 — 고침
- 화면판이 실제로 보이는 월드 크기를 시뮬에 알려 준다 (`g.view`). 적은 그 바깥에서 나타나고, 폭탄은 보이는 범위를 지운다. 시뮬은 1280×720 기준 그대로.

### 성능 확인
- 스테이지 10, 틱 하나: 강한 빌드(적 최대 50) p99 0.3ms, 약한 빌드(적 최대 123) p99 0.5ms. 60fps 한 프레임(16ms)에 한참 남는다.

### 봇 울타리 쿠션 조준 — 넣음 (시뮬 정확도)
- 직접 노릴 무리가 없으면 울타리에 비친 자리로 조준한다. 검증장에서 공 몫 28% → 43%.
- 런 완주는 그대로 (15/24, 캐릭터별도 같음). 큐가 낮은 것은 봇 탓이 아니라 체력 80이 약한 탓이 커 보인다.

## 저녁에 같이 볼 것

1. **페인트 총 방향**: 칠하기만 하고(밀지 않음), 색 공 규칙에서는 내 공 색으로 칠한다. 손맛이 맞는지. 다른 후보는 "1초 마름".
2. **색 공 규칙을 기본으로 갈지**: 기존 규칙은 오늘 페인트 수정과 기믹 적이 겹쳐 많이 어려워졌다 (완주 25%). 색 공으로 가면 기존 규칙은 정리.
3. **캐릭터 격차 (색 공 규칙)**: 올리 6/6, 팔레 4~6/6, 양치기 3/6, 큐 2/6. 큐 체력(80)이나 고유 특성 쪽 보강, 또는 팔레 약화.
4. **맵 기믹 5개 손맛**: 개울(2), 안개(4), 꽃 범퍼(6), 바위(7), 돌풍(8). 링크 끝에 `#stage2`, `#stage4`, `#stage6`, `#stage7`, `#stage8`을 붙이면 바로 해 볼 수 있다.
5. **기믹 적**: 가시 젤리(무기로 안 밀림), 겁쟁이 양(도망). 화면에서 읽히는지.
6. **효과음**: 합성음이라 투박하다. 방향만 맞으면 나중에 다듬는다.
