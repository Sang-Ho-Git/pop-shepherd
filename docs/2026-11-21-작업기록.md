## 시간순

### 09:10 준비
- 봇이 색 공을 던진다: 지금 공과 같은 색으로 2마리 이상 붙은 무리 중 가장 가까운 곳, 없으면 같은 색 1마리.
- 시뮬에 색 공 규칙 옵션 (`npm run campaign -- --ball`).
- 비교 시뮬 `tools/probe.ts` + 조건 목록 `tools/variants.ts`: 같은 시드로 조건만 바꿔 완주를 비교한다.

### 09:40 손맛 (트리 4.2) — 넣음
- WebAudio 합성 효과음: 팝, 공 던지기, 공 붙음, 피격, 휘슬, 레벨업, 보스 등장, 상자, 클리어.
- 콤보 음정: 연쇄 단계마다 5음계로 한 칸씩 올라간다.
- 히트스톱: 연쇄 팝이나 5마리 이상 팝에서 0.04~0.09초 멈춘다.
- 소리 켜기/끄기: 타이틀 버튼, 또는 M 키.

### 10:10 페인트 총: 무엇이 센가
- 먼저 완주율로 비교했다 (같은 시드, 양치기·큐·올리 6판씩). 차이가 거의 없었다.
  - 기존 규칙: 보통 14/18, 페인트 총 금지 13/18
  - 색 공 규칙: 보통 16/18, 페인트 총 금지 14/18
- 그래서 지표를 바꿨다: 팝마다 누가 일으켰는지 센다 (무기·공·휘슬·폭탄, 연쇄 팝은 처음 일으킨 쪽 몫). `stats.popsBy`, 도구 `tools/share.ts`.
- 검증장, 무기 하나만 바꿔 끼우고 나머지는 충격파·토템 Lv3 (4판씩):

| 무기 | 기존: 그 무기 몫 | 색 공: 무기 몫 / 공 몫 |
|---|---|---|
| 킥 Lv3 | 23% | 17% / 28% |
| 올가미 Lv3 | 31% | 24% / 23% |
| 회오리 Lv3 | 29% | 15% / 28% |
| 페인트 총 Lv3 | 56% | 36% / 31% |
| 페인트 총 7A / 진화 | 62% / 62% | 44% / 48% |

- 결론: 페인트 총은 "칠하고 → 옆 무리로 밀어 넣으면 → 알아서 터지는" 구조라, 플레이어가 할 일을 대신한다. 완주율보다 이게 "사기"의 정체다. 색 공 규칙에서는 공보다 더 많이 터뜨린다.

### 10:30 기믹 적·바위 (트리 3.2, 3.3) — 시험 중
- 가시 젤리: 플레이어 무기로 밀리지 않는다 (팝 충격파·휘슬은 밀린다). 매치로는 터진다. 스테이지 4부터 짝의 12~18%.
- 겁쟁이 양: 220px 안으로 다가가면 도망간다. 빠르다(95). 스테이지 6부터 12~18%.
- 바위: 스테이지 7 "돌무지 고개"에 6개. 길을 막고, 날아간 적은 울타리처럼 튕긴다 (쿠션).
- 화면에도 그렸다: 가시, 귀, 회색 돌.

### 11:00 처음 하는 사람 안내 (트리 4.3·4.4) — 넣음
- 스테이지 1에서 시간에 맞춰 짧은 안내가 하나씩 뜬다 (처음 세 판만). 규칙(색 공 / 기존)에 맞는 문장.
- 색 공: 조준·던지기 → 3마리 채우면 팝, 빛나는 무리 → 하나뿐이면 붙음 → 연쇄와 휘슬.
