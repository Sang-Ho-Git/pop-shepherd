# 2026-11-26 연쇄 가시화

사용자 피드백: "연쇄에 대한 정확한 메커니즘이 느껴지지 않고 재수 좋게 연쇄된 느낌. 공이 터지거나 휘슬로 떨어뜨렸을 때 반동이 커서 연쇄될 것 같은데 안 되고 진행되는 경우도 많음."
규칙은 그대로다 (팝 충격파에 날아간 적이 1초 안에 같은 색과 부딪혀 3마리 이상이 되면 연쇄, 휘슬은 밀기 전용). 보이게만 했다 — 게임 상태·난이도는 바뀌지 않는다.

## 연출 (web/render.ts 위주, main.ts는 이벤트 처리만)

| 연출 | 보이는 모양 | 구현 |
|---|---|---|
| 연쇄 가능 표시 | 팝 충격파로 날아가 인정 시간(1초)이 남은 적: 자기 색의 두껍고 긴 꼬리 + 몸 둘레 빛 고리, 남은 시간만큼 옅어진다 | `drawEnemy` (`e.chainT`·`chainDepth`) |
| 연쇄 불가 표시 | 휘슬·무기로 날린 적(`cause`가 whistle·무기)은 옅은 회색/흰 꼬리 | `drawEnemy` (`muted`) |
| 연쇄 예감 | 연쇄 가능 적의 진행 방향 120px 안에 같은 색이 있으면 그 적과 맞닿은 같은 색(최대 5마리)에 점선 표적 고리 + 날아가는 적 앞에 화살표 | `drawChainHints` |
| 연쇄 선·글자 | 앞 팝 자리에서 새 팝 자리로 빛줄기, "연쇄 N!" (단계가 오르면 글자가 커지고 화면이 더 흔들림), 음 높이는 기존 `sfx.pop(size, chainDepth)` | `handleEvents` pop |
| 아깝게 안 됨 | 같은 색 1마리에만 맞아 붙으면 "2/3" + 작은 고리 (이벤트 `chain-miss`), 다른 색·회색에 맞아 연쇄가 막히면 튕김 불꽃 (이벤트 `chain-bounce`) | `impacts.ts`, `handleEvents` |
| 휘슬 | 퍼지는 보랏빛 이중 고리 (팝 충격파와 구별), 휘슬로 날린 적은 회색 꼬리 | `handleEvents` whistle |

시뮬 이벤트 추가: `chain-miss {id,x,y,size,need,color,chain}`, `chain-bounce {id,x,y}` — 읽기 전용이다. `chain-miss`의 무리 크기는 팝 자격이 있는 발사(내 공·연쇄)에서만 계산한다 (무기가 날린 적은 예전과 같은 비용, "2/3"도 표시하지 않음).
테스트 `tests/chainfx.test.ts` (4건), 기존 결정론·매치 테스트 모두 통과.
